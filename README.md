# My very own LLM

We are designing a primitive, home-made LLM with 20 million parameters. It is meant to run on the CPU of a home computer, and on a GPU as well.

## Why

The main goal of this project is to learn, by doing, how LLMs work and what AI is.

## Free software

Once the model is finished, it is meant to fully comply with free software standards (free as in freedom), so that everyone who has the means can run it on their own computer.

Anyone may download it, build on it, do research with it, or simply use it.
